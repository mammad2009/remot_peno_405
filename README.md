# Peugeot405Control (v2.2)

برنامه‌ی کنترل ماکت پنوماتیک پژو ۴۰۵ از طریق بلوتوث (HC-05) — دو زبانه (فارسی / English).

## مراحل برنامه
1. **صفحه‌ی شروع** – آرم شیر پژو با برق نور، بعد اسم PEUGEOT و آرم «405 GLX». (با یک لمس رد می‌شود)
2. **صفحه‌ی اتصال** – یک دکمه‌ی اتصال به HC-05.
3. **ریموت پژو** – قفل `K` / باز `U`؛ بعد از «باز» می‌رود داخل منو.
4. **برنامه چهار بخش دارد** (نوار پایین):
   - **کنترل**: جلو / عقب / هر دو، میباخ، ارتفاع فابریک، حالت نمایشگاهی.
   - **چراغ‌ها**: ماشین از بالا با لامپ‌های زنده، سه دکمه‌ی گرد (جلو کوچک / نور بالا / عقب)،
     راهنماها (چپ / فلاشر / نوبتی / راست) و ۶ افکت چراغ (عربی، پلیسی، استروب، موج، ضربان، سریع).
   - **منو** (= حالت کارخانه): با ورود، فرمان `Y` فرستاده می‌شود و ماکت کف‌خواب می‌شود؛ با خروج یا بستن برنامه `V`.
     داخلش: تعلیق و سرووها (زاویه‌ی کف/متوسط/سقف هر محور با تست زنده و اعمال روی ماکت)،
     چشم‌ها و افکت‌ها (پیش‌نمایش همه‌ی حالت‌های چشم، واکنش‌ها، صحنه‌ها و ۴۰ متن روی خود نمایشگر ماکت)،
     باتری (درصد، ولتاژ، هشدار، کالیبراسیون، شبیه‌سازی) و سیستم (وضعیت، ری‌استارت، برگشت به پیش‌فرض).
   - **فرمان‌ها**: زبان، ویرایش و ارسال فرمان‌ها.
5. تغییر سریع زبان: دکمه‌ی `EN` / `فا` بالای صفحه.

## فرمان‌های جدید (هماهنگ با car_emo_eyes_v21_esp8266.ino)
| کار | فرمان |
|---|---|
| ورود به حالت کارخانه | `Y` |
| خروج از حالت کارخانه | `V` |
| شروع نمایشگاهی | `S` |
| توقف نمایشگاهی | `E` |

منوی ماکت (فرمان‌های خطی `#GET` ، `#SET:...` ، `#SAVE` ، `#POSE:n` و ...) به کد `car_emo_eyes_v23_esp8266.ino` یا جدیدتر نیاز دارد.
باتری را از بخش منو ← باتری روشن کن؛ بعدش ماکت هر ۵ ثانیه `BAT:87` می‌فرستد و درصد بالای صفحه نشان داده می‌شود.

فرمان‌های قبلی (`F B R L 1 2 X Z M N K U 0`) بدون تغییر هستند و همه از «فرمان‌ها» قابل ویرایش‌اند.

## ساخت با GitHub
فایل‌ها را در ریشه‌ی مخزن بگذار؛ `.github/workflows/build.yml` با هر push فایل APK را می‌سازد
(Actions ← Build APK ← Artifacts).

## نکته‌ی مهم درباره‌ی ذخیره نشدن عددها
منو هیچ‌چیز را در EEPROM ذخیره نمی‌کند. زاویه‌ها و تنظیمات فقط تا خاموش شدن ماکت می‌مانند.
عددی که خوشت آمد را با دکمه‌ی «کپی عددها برای کد» بردار و بالای فایل ماکت (`DEF_REST_F` و ...) بنویس.
